# Job Market Skills Analytics

Итоговый проект №7 по дисциплине **Programming for Data Analysis and Database**, Applied Artificial Intelligence.

Проект исследует историческую выборку вакансий LinkedIn: упоминания навыков, зарплаты, должности, регионы и даты публикации. Данные обрабатываются блоками, сохраняются в нормализованной SQLite и Parquet. Streamlit показывает интерактивные графики и фильтры.

## Участники

- **Дархан Зейнулла** - EDA, визуализации, временные ряды, сравнение прогнозов, Streamlit, отчёт и презентация.
- **Совместно** - интеграция модулей и проверка результатов.

## Быстрый запуск

Среда запуска: Windows и Python **3.11**, отдельная виртуальная среда `.venv`. Команды выполняются из родительской папки проекта. Первичная загрузка датасета требует интернета; дашборд с готовой базой работает локально.

```powershell
cd job_market
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py
```

Адрес дашборда: http://localhost:8501, если порт не изменён в настройках Streamlit. Остановка: Ctrl+C. Команды установки и запуска используют Python из `.venv` без активации среды.

Путь к Python в Linux/macOS: `.venv/bin/python`. Для PDF необходим шрифт Arial (Windows) или DejaVu Sans (Linux). Ориентировочные ресурсы: 2 GB свободной RAM и 2 GB свободного диска.

В комплекте `submission.zip` есть готовые компактные данные и результаты. Для полного пересчёта:

```powershell
python main.py all
```

Отдельные этапы обработки:

```powershell
python main.py download
python main.py build --chunksize 10000
python main.py analyze
python main.py documents
python main.py menu
python -m pytest -q
```

`download` повторно использует корректный архив; `build` пересобирает аналитические файлы. При неудаче построения готовая `jobs.db` не заменяется незавершённой базой. `documents` требует предварительно выполненного анализа. `analyze` также создаёт дополнительный аналитический CSV для измерения форматов; этот CSV исключён из архива и Git.

Загрузчик также поддерживает локальный архив версии 13 по пути `data/raw/linkedin-v13.zip`: команда `download` проверяет и распаковывает его без повторного скачивания.

## Методика

**Зарплата.** Только USD и BASE_SALARY, без пересчёта валют. Положительная med_salary имеет приоритет; иначе середина min/max при наличии обеих корректных границ. Коэффициенты: YEARLY ×1, MONTHLY ×12, WEEKLY ×52, BIWEEKLY ×26, HOURLY ×2080. Неизвестный период и неполный диапазон дают пропуск. Неизвестная зарплата не заменяется средним. Все допустимые исходные выбросы сохранены; графики с ограничением IQR явно подписаны. Медиана KPI использует все допустимые зарплаты.

**Навыки.** `platform` - широкие функции LinkedIn (Sales, Engineering и т.д.). `dictionary` - 32 конкретных навыка, извлечённых регулярными выражениями из названия, описания и skills_desc. Один навык учитывается один раз на вакансию. Словарные упоминания не равнозначны обязательным требованиям. Ручная эталонная разметка отсутствует, поэтому precision и recall извлечения не оценивались.

**Регионы и роли.** Регион - двухбуквенный суффикс location. Остальное - Other / unspecified. Категории ролей - объяснимые правила по title, без обученной классификации. Порядок правил имеет значение. Пропуск remote_allowed означает неизвестность, а не отсутствие удалённой работы.

**Время.** original_listed_time используется как дата первоначальной публикации, listed_time - запасной источник при пропуске. Миллисекунды UTC переводятся в календарную дату UTC. Снимки имеют неодинаковое покрытие. Пропуски дат не заполняются нулём. Для rolling, STL и прогноза выбран самый длинный календарно непрерывный отрезок дат с наблюдениями; крайние даты отброшены как потенциально неполные. Это не гарантирует полноту покрытия каждого оставшегося дня. Есть `resample` по неделям и месяцам, trailing rolling(7), STL(period=7, robust=True). Декомпозиция только описательная.

**Прогноз.** Baseline Naive, Moving average 7 и Linear regression с трендом последних 14 дней. Последние 14 дней сегмента разделяются на validation 7 и test 7, вся более ранняя история - начальное обучение. На каждом шаге прогнозируется один день и затем раскрывается факт. Прогноз на неделю без новых наблюдений не выполняется. Модель выбирается по validation MAE, test служит отдельной оценкой. Окна заданы заранее. Время - медиана 5 проходов теста, память - tracemalloc отдельного прохода. Модель не должна считаться доказанно лучшей для всего рынка на основании короткого теста.

**Хранение.** CSV baseline, Parquet и SQLite читают одинаковые столбцы одной компактной таблицы, затем выполняют одинаковый groupby в Pandas. Результаты проверяются с rtol=1e-8. Время - медиана 3 запусков после прогрева. Файловый кэш не очищался. Пиковая память tracemalloc учитывает выделения Python и часть библиотечных буферов, не все нативные выделения и не RSS. Память типов `memory_usage(deep=True)` измеряет размер представления блоков, не пик ETL. Сравнение не подменяет большой исходный CSV узким Parquet.

## SQL

Все запросы из `sql/queries.sql` выполняются `pd.read_sql_query`, их результаты сохраняются в CSV.

| № | Результат | Конструкции |
|---|---|---|
| 01 | Упоминания словарных навыков и доля всех вакансий | JOIN, GROUP BY, подзапрос |
| 02 | Функциональные категории LinkedIn | JOIN, GROUP BY |
| 03 | Средняя зарплата по регионам с n ≥ 100 | GROUP BY, HAVING |
| 04 | Работодатели по числу вакансий | JOIN, GROUP BY |
| 05 | Количество вакансий по датам | GROUP BY |
| 06 | Top-3 названия вакансий внутри региона | CTE, ROW_NUMBER |
| 07 | Зарплаты выше среднего своей категории | CTE, JOIN |
| 08 | Месячные количества и предыдущий наблюдаемый месяц | CTE, LAG |
| 09 | Средняя зарплата при упоминании навыка, n ≥ 50 | JOIN, HAVING |
| 10 | Покрытие зарплаты по уровню опыта | GROUP BY |
