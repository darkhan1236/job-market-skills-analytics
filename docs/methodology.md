# Методы и архитектура проекта

## Обзор

Проект анализирует исторические вакансии LinkedIn: упоминания навыков, должности и предлагаемые зарплаты по регионам. Python читает CSV блоками, проверяет данные и сохраняет их в SQLite. SQL и Pandas формируют сводки, Streamlit предоставляет фильтры и графики. Три метода однодневного прогноза сравниваются по MAE на более поздних датах. Результаты характеризуют исследуемую выборку.

## Технические пояснения

**Почему SQLite?** Не нужен отдельный сервер, база переносится одним файлом; поддерживаются JOIN, CTE и оконные функции. Ограничения и индексы делают связи проверяемыми.

**Зачем Parquet, если есть SQLite?** Parquet удобно хранит компактную аналитическую таблицу и позволяет читать выбранные столбцы. SQLite используется для отношений и параметризованных запросов. Они решают разные задачи; результаты сравнения относятся к определённой операции.

**Что означает MAE?** Среднее абсолютное расстояние между прогнозом количества вакансий и фактом. Единица измерения — вакансии в день. Чем меньше, тем точнее на этом тесте.

**Почему три временных части?** Начальная история обучает метод, validation выбирает подход, test даёт отдельную последующую оценку. Выбор лучшего по test привёл бы к оптимистичной оценке.

**Почему наблюдения теста добавляются в историю?** Это явно заданный сценарий однодневного прогноза: к следующему дню предыдущий факт уже известен. Будущие факты не доступны. Для недельного прогноза без обновления нужна другая проверка.

**Покрытие временного ряда.** Пропущенные даты обозначают неизвестное покрытие сбора, поэтому не заменяются нулевым количеством вакансий.

**Почему STL считается на всём сегменте?** Для описательного графика. Её компоненты не передаются в модель, иначе сглаживание могло бы раскрыть будущую информацию.

**Как считаются навыки?** Проверяются регулярные выражения в тексте. Список уникален внутри вакансии. Словарь ограничен и не распознаёт контекст отрицания или степень обязательности. Метрики качества извлечения требуют ручной разметки, которой в текущем проекте нет.

**Почему суммы долей больше 100%?** Одна вакансия может содержать несколько навыков. Для каждого навыка знаменатель — все вакансии выбранной группы.

**Что такое IQR?** Q3−Q1; потенциальные выбросы лежат ниже Q1−1.5×IQR или выше Q3+1.5×IQR. Это правило поиска необычных значений, а не доказательство ошибки. Поэтому значения сохраняются, график ограничивается отдельно.

**Почему медиана полезнее среднего?** Она меньше реагирует на экстремальные зарплаты. Но даже медиана не устраняет смещение из-за того, что зарплату публикуют не все работодатели.

**Измерение памяти.** Размер представления блоков измеряется через memory_usage(deep=True), пиковые выделения Python для сравниваемой операции — через tracemalloc. Эти показатели не являются полным пиком RSS процесса.

**Как код обрабатывает ошибки?** main.py перехватывает исключения, печатает причину и для пакетной команды возвращает ненулевой код. Меню позволяет продолжить работу после ошибки. Download проверяет HTTP и ZIP, схема проверяет ссылки и ключи.
